## Required Fix: Test Isolation / Queue Congestion

### Problem
Integration tests create real runs that enqueue real Celery tasks. When the full test suite
runs (70+ tests), it creates 50–70 concurrent runs. The 2-concurrency worker pool processes
them serially. Long-running tests (P6, P8) poll for completion with a 1200s timeout, but
the queue backlog means their run never reaches QA/judge within the timeout window.

Observed: 55 `running` runs clogging the queue; workers occupied; QA step never picked up.

### Fix (implement before P10 sign-off)

**Option A — Add cleanup after each integration test class** (preferred)

Add a `conftest.py` autouse fixture that cancels any run created by the test and purges
the Celery queue after each class:

```python
# control-api/tests/conftest.py — add this fixture

@pytest.fixture(autouse=True)
def _cancel_test_runs_on_teardown(client, request):
    """Collect run IDs created during a test and cancel them on teardown.

    Each test that creates a run should register the run_id via
    request.addfinalizer or the test-local list approach below.
    """
    created_runs: list[str] = []
    yield created_runs
    for run_id in created_runs:
        try:
            client.post(f"/runs/{run_id}/cancel")
        except Exception:
            pass
```

**Option B — Dedicated test worker with queue isolation** (more robust)

Run integration tests against a separate Celery queue (e.g., `squad.test-steps`) so test
tasks don't compete with real tasks. Add a `WORKER_QUEUE` env var and set it to
`squad.test-steps` in CI.

**Option C — Skip LLM-dependent tests in CI until E2E isolation exists** (quick mitigation)

Mark `test_p6_approval_evidence_flow`, `test_p8_optional_steps`, and similar slow tests
with `@pytest.mark.slow` and exclude from the fast suite. Run them in a separate job that
waits for the queue to drain.

**Recommended immediate action**: implement Option A for the per-class cleanup + add an
explicit `celery purge` before the slow P6/P8 tests (via a session-scoped autouse fixture).
