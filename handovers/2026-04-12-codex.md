## Current functional state

- Approval API now exists:
  - `POST /api/v1/approvals`
  - `GET /api/v1/approvals/{approval_id}`
  - `GET /api/v1/entities/{entity_type}/{entity_id}/approvals`
- Approval decisions require:
  - non-pending status
  - comment
  - at least one evidence row
- Approving an older revision without override is blocked.
- Later entity edits mark older approval decisions stale through `insert_revision`.
